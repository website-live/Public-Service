# Public Service CEP Website

A simple, responsive one-page website built with only:

- `public/index.html` — all visible website content. Edit service names, descriptions, Google Maps links, and team members here.
- `public/styles.css` — all layout, colors, spacing, and responsive CSS.
- `public/main.js` — small mobile navigation and safe external-link behavior.
- `worker.js` — static file handler used by the project scaffold.

## Easy editing

1. Open `public/index.html`.
2. Find a service card or team member.
3. Change the text inside the HTML tags.
4. Change a Google Maps URL inside `href="..."`.
5. Save and publish the project.

No React, Tailwind, database, map library, framework, or complex JavaScript is needed for this version.
